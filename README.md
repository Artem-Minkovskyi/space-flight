# Space Flight — Лабораторна робота №2

**Тема: Об'єкти, прототипи та this — модель сутностей**

## 1. Опис проєкту

Space Flight — браузерна гра, розроблена на JavaScript із використанням Canvas 2D. Гравець керує космічним кораблем, знищує астероїди, збирає бонуси та отримує очки.

У другій лабораторній роботу було розширено архітектуру гри: реалізовано систему сутностей, наслідування, композицію поведінки, обробку зіткнень, здоров'я та відродження корабля.

## 2. Використані технології

- JavaScript (ES Modules, Classes)
- HTML5, CSS3
- Canvas 2D API
- Vite
- ESLint, Prettier
- requestAnimationFrame()

## 3. Керування

| Клавіша | Дія              |
| ------- | ---------------- |
| W / ↑   | Рух уперед       |
| S / ↓   | Рух назад        |

| Space   | Стрільба         |

Мета гри — знищувати астероїди, збирати бонуси та набирати очки.

## 4. Архітектура сутностей та наслідування

Основою ігрової моделі є базовий клас `Entity`, який містить спільні властивості сутностей:

- `id` — унікальний ідентифікатор;
- `position` — позиція;
- `velocity` — швидкість;
- `radius` — радіус;
- `kind` — тип сутності;
- `update()` — оновлення стану;
- `destroy()` — позначення сутності для видалення.

Унікальні ідентифікатори генеруються за допомогою приватного статичного поля `#nextId`.

Від `Entity` успадковуються:

- `Ship` — корабель із приватним полем здоров'я `#hp`, методами `takeDamage()` та `heal()`;
- `Bullet` — снаряд із часом життя `ttl`;
- `Asteroid` — астероїд із власним запасом здоров'я;
- `Pickup` — бонус для відновлення здоров'я;
- `Explosion` — ефект вибуху з анімованими частинками.

Для математичних обчислень використовується клас `Vector2`, методи якого повертають нові вектори, не змінюючи початкові об'єкти.

## 5. Світ гри та зіткнення

Клас `World` керує всіма ігровими сутностями за допомогою `Map`, де ключем є ідентифікатор об'єкта, а значенням — сама сутність.

Реалізовані методи:

- `spawn()` — додавання сутності;
- `despawn()` — позначення сутності для видалення;
- `sweep()` — безпечне видалення знищених сутностей;
- `step()` — оновлення ігрового світу;
- `ofKind()` — генератор для отримання сутностей певного типу;
- `[Symbol.iterator]()` — підтримка ітерації.

Клас `collision.js` реалізує перевірку зіткнень двох кіл. Кулі завдають шкоди астероїдам і кораблю, а зіткнення корабля з астероїдом зменшує його здоров'я.

Після знищення астероїда нараховуються очки та створюється вибух.

## 6. Композиція поведінки

Для демонстрації композиції реалізовано модуль `behaviors.js`.

Функція `attachHoming()` додає сутності поведінку переслідування цілі без створення окремого класу-нащадка.

Функція `updateHoming()` поступово змінює швидкість і напрямок руху сутності в бік цілі.

Цю поведінку можна підключати до різних типів об'єктів, наприклад астероїдів або куль.

Клас `Pickup` також демонструє окрему поведінку: бонус залишається нерухомим, взаємодіє з кораблем при зіткненні та відновлює його здоров'я.

Такий підхід дозволяє додавати нові можливості об'єктам без ускладнення дерева наслідування.

## 7. Контекст виконання та this

У JavaScript значення `this` залежить від способу виклику функції, а не від місця її оголошення.

Наприклад, передавання методу корабля безпосередньо як callback:

```js
setTimeout(ship.fire, 100);
```

може призвести до втрати контексту `this`, оскільки метод викликається без об'єкта-власника.

Виправити проблему можна трьома способами:

1. **bind()**

```js
setTimeout(ship.fire.bind(ship), 100);
```

Перевага: створює функцію зі зафіксованим контекстом. Недолік: створюється нова функція.

2. **Стрілкова функція**

```js
setTimeout(() => ship.fire(), 100);
```

Перевага: виклик методу через об'єкт зберігає правильний контекст. Недолік: створюється додаткова функція-обгортка.

3. **Обгортка через звичайну функцію**

```js
setTimeout(function () {
  ship.fire();
}, 100);
```

Перевага: простий і зрозумілий спосіб. Недолік: також створюється додаткова функція.

Стрілкові функції використовують лексичний `this` і не створюють власного контексту, тому їхній `this` не можна змінити за допомогою `bind()`.

## 8. Додаткові можливості гри

- Система здоров'я корабля.
- Відновлення здоров'я за допомогою бонусів.
- Знищення астероїдів і нарахування очок.

## 10. Висновок

Під час виконання лабораторної роботи було розширено гру Space Flight за допомогою об'єктно-орієнтованої моделі сутностей.

Реалізовано класи, наслідування, приватні поля, керування сутностями через Map, ітератори, генератори, обробку зіткнень і композицію поведінки.

Також досліджено особливості контексту `this`, роботу прототипного ланцюжка та способи безпечного передавання методів як callback.

У результаті створено розширену модель ігрового світу з можливістю додавання нових типів сутностей і поведінки.
